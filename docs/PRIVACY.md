# Privacy

SoulsTracker is a local Windows application.

- Settings, counters, and optional local text exports remain on the user's machine.
- The hosted overlay requires explicit consent and an operator-issued single-use setup code. Desktop generates separate read/write capabilities locally. Before the first request, it stores the complete pending setup in a dedicated Windows current-user DPAPI-protected file, separate from the active protected configuration, tracker database, and exports. Only role/identity-bound verifiers are sent during provisioning.
- Publication sends the accepted death display value/availability and applied appearance (including custom title and font name) to Cloudflare. It does not send game/save paths, source identities, character/slot names, process details, raw observations or adjustment metadata. Cloudflare does not calculate totals or synchronize cloud totals back into local counters.
- Cloudflare retains the last published display until operator deletion and processes operational connection metadata such as IP addresses and timing. Application telemetry, analytics and accounts are not added. Provider recovery/backups may outlive application deletion.
- Hosted setup accepts only https://overlay.beingkairo.com and requires a pre-admitted operator slot. Local tracking and TXT remain usable without hosted setup. There is no local overlay fallback in the composed hosted path.
- The optional update check contacts GitHub's public latest-release endpoint when you press **Check for updates**, or once when the app opens if you enable **Check for updates on startup**. Startup checks are off by default; changing the setting applies to future launches. The check sends no account, token, analytics, machine identifier, or save data, and never downloads or installs anything automatically. Only an automatic startup check can show a dismissible update dialog for a verified newer version. Manual checks show their result in Settings. **Open release page** opens https://beingkairo.com/tools/souls-tracker/ only when you choose it.
- **Copy URL** includes only read authority in a fragment, never write authority. Anyone possessing that URL can read the overlay. Keep the Overlay URL and streaming-software configuration private. The connection panel displays only the origin and sanitized status.
- The setup code is grant-only and contains no read or write authority. Write authority is generated locally and used only for authenticated HTTPS publication, never in the Overlay URL, browser assets, ordinary settings, database, or TXT output.
- **Remove connection** stops publication and removes only the active protected configuration on this PC. It does not delete pending setup, revoke capabilities, or delete hosted state; request those actions from the operator. Pause, cancellation, and restart preserve pending setup. Destructive abandonment requires confirmation that the operator invalidated or reset the slot.
