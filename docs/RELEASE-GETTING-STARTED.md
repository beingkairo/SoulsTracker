## Getting Started

New to SoulsTracker? The full setup guide is in the [README](https://github.com/beingkairo/SoulsTracker#start-streaming).

Hosted setup requires explicit consent and an operator-issued pairing file for an authorized HTTPS host. This development build has no authorized production host. Local tracking and TXT work without pairing. With an authorized hosted service, either startup order is supported; replace existing local OBS URLs once using **Copy OBS URL**. Keep pairing files and OBS URLs private.
