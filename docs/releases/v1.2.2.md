# SoulsTracker v1.2.2

SoulsTracker v1.2.2 gives Elden Ring players a reliable way to correct missed saved death totals and makes those controls available through the existing global hotkeys.

## Elden Ring missed deaths

- Add or remove missed deaths when Elden Ring's saved total does not include them.
- This can help with some PvP and invasion-style deaths, including the Great Jar challenge, which may be omitted from the saved total.
- The displayed Total Deaths value combines the saved total with your adjustment, so it stays correct as the game continues saving.

## Global hotkeys

- Your existing shared global hotkeys now add or remove Elden Ring missed-death adjustments.
- The same hotkeys continue to work with the manual Bloodborne and Demon Souls counters.

## Important

SoulsTracker is read-only. It does not edit saves, write to game memory, inject code, automate gameplay, or change game values.

Download `SoulsTrackerV1.2.exe` for the normal Windows installer. The portable ZIP, SHA-256 checksums, and SPDX SBOM are included with this release for users who prefer them.
