# SoulsTracker v1.3.1

## Highlights

- Added optional OBS startup recovery so Browser Sources stay ready when OBS opens before SoulsTracker.
- Added a manual update check in Settings.
- Improved save selection for Black Myth: Wukong and Lies of P. Choose another valid slot or character from the same save folder at any time.
- Added a clear status for new save files with zero recorded deaths.
- Fixed the boss list when changing from a filtered game to a game with one all-bosses list.

## Supported games

- Demon Souls
- Dark Souls: Remastered
- Dark Souls II: Scholar of the First Sin
- Dark Souls III
- Bloodborne
- Sekiro: Shadows Die Twice
- Elden Ring
- Black Myth: Wukong
- Lies of P

SoulsTracker is read-only. It keeps game files and game memory untouched.
