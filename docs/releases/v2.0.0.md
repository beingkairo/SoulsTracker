# SoulsTracker v2.0.0

## Compatible games

- Demon Souls: manual death counter.
- Dark Souls: Remastered: automatic tracking for the validated Windows 1.0.0.0 executable build only.
- Dark Souls II: Scholar of the First Sin: automatic tracking for the two validated Windows 1.0.3.0 executable builds only; the original Dark Souls II is not supported.
- Dark Souls III: automatic tracking for the validated Windows 1.15.2.0 executable build only.
- Bloodborne: automatic tracking for the validated Bloodborne title (CUSA03173) running in shadPS4 on Windows; console play is not tracked automatically.
- Sekiro: Shadows Die Twice: automatic tracking for the validated Windows 1.6.0.0 executable build only.
- Elden Ring: automatic tracking from a selected Windows save and character; totals update after the game saves.
- Black Myth: Wukong: automatic tracking from a selected Steam or Epic save on Windows; totals update after the game saves.
- Lies of P: automatic tracking from a selected Steam character save on Windows; totals update after the game saves.

## Latest changes

- Focused SoulsTracker on total deaths: boss lists, death sounds, the local browser overlay and its background startup helper have been removed. Existing local OBS URLs must be replaced.
- Added a private hosted Total Deaths Overlay URL for OBS, with appearance settings in the desktop app. The last published display remains online after the app closes; a new browser load still requires a connection.
- Improved count handling when readers briefly lose access to a game or save, when switching characters or saves, and when an automatic count drops. Bloodborne now uses automatic tracking only.
- Updated save selection, reader status, and desktop controls, including an appearance preview and optional startup update checks.
- The Windows installer now checks for Microsoft WebView2 Runtime and can install it when needed. Interactive uninstall offers a choice to keep or delete local SoulsTracker settings.

## Notes

SoulsTracker is read-only: it does not modify game memory or saves. Local tracking and TXT output work without the online Overlay. Keep your Overlay URL private.
