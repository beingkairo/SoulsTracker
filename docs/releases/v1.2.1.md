# SoulsTracker v1.2.1

SoulsTracker v1.2.1 makes the Total Deaths overlay more dependable during a stream and restores Elden Ring boss names.

## Total Deaths overlay

- The Skull-only Total Deaths icon stays visible when the title is blank.
- Total Deaths now anchors inside the fixed OBS Browser Source canvas for predictable left, center, and right placement.
- Automatic memory-based death totals remain visible during brief game loading transitions.

## Boss list

- Elden Ring boss display names have been restored to their canonical forms.

## Important

SoulsTracker is read-only. It does not edit saves, write to game memory, inject code, automate gameplay, or change game values.

Download `SoulsTrackerV1.2.exe` for the normal Windows installer. The portable ZIP, SHA-256 checksums, and SPDX SBOM are included with this release for users who prefer them.
