# SoulsTracker v1.3.0

SoulsTracker v1.3.0 adds read-only Lies of P save tracking and a complete Lies of P boss checklist.

## Changes

- Automatically discover local Steam Lies of P character saves.
- Select and track the active character save, including paired character-save files.
- Read the saved lifetime death total without editing the save.
- Track Lies of P boss progress with the base-game and Overture checklist.

## Supported games

- Demon Souls
- Dark Souls: Remastered
- Dark Souls II: Scholar of the First Sin
- Dark Souls III
- Bloodborne
- Sekiro: Shadows Die Twice
- Elden Ring
- Black Myth: Wukong
- Lies of P

## Important

SoulsTracker is read-only. It does not edit saves, write to game memory, inject code, automate gameplay, or change game values.

Download `SoulsTrackerV1.3.exe` for the normal Windows installer. The portable ZIP, SHA-256 checksums, and SPDX SBOM are included with this release for users who prefer them.
