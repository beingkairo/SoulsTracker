# SoulsTracker v1.2.0

SoulsTracker v1.2.0 adds automatic save-file tracking for Elden Ring and Black Myth: Wukong, expands the boss checklist, and makes stream setup more predictable.

## Elden Ring

- Automatically discovers local `ER0000.sl2` saves in common PC locations.
- Lets you choose the character you are streaming and shows the character name and level.
- Reads that character's lifetime death total directly from the save.
- Keeps Browse and Rescan available for nonstandard save locations.
- Hides empty character slots from the character picker.

## Black Myth: Wukong

- Automatically discovers supported Steam and Epic PC save slots.
- Selects an unambiguous slot automatically or lets you choose when multiple slots are found.
- Reads the slot's lifetime death total and shows useful details such as level, play time, and last-saved time when available.
- Adds a complete Black Myth: Wukong boss checklist.

## Better boss tracking and overlays

- Search any game's boss list and return to the normal list by clearing the search. Search also resets when you change games or restart SoulsTracker.
- Use All, Main, and DLC boss filters when a game's content supports those choices. Games without DLC keep the simpler All Bosses view.
- The Boss List browser overlay is now a fixed **600 x 1080** widget. Long names wrap inside the widget instead of shifting the list during a stream.
- Empty boss selections are blank on the overlay, while the app clearly says that no bosses are being displayed.
- Valid save-file tracking now starts from zero when no death value is available instead of showing an error-like unavailable state.

## Setup and reliability improvements

- Game and save selection are clearer and more compact.
- The selected game is restored reliably when SoulsTracker starts.
- Death-sound volume changes save automatically.
- Shutdown reliability has been improved and is covered by a packaged-app shutdown benchmark.

## Important

SoulsTracker is read-only. It does not edit saves, write to game memory, inject code, automate gameplay, or change game values.

Elden Ring and Black Myth: Wukong death totals update after the game writes its save, so a new death can take a moment to appear.

Download `SoulsTrackerV1.2.exe` for the normal Windows installer. The portable ZIP, SHA-256 checksums, and SPDX SBOM are included with this release for users who prefer them.
