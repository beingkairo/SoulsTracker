# SoulsTracker

A simple death counter for supported games.

[Download the latest release](https://github.com/beingkairo/SoulsTracker/releases/latest).

## Compatible games

- Demon's Souls
- Dark Souls Remastered
- Dark Souls II: Scholar of the First Sin
- Dark Souls III
- Bloodborne
- Sekiro: Shadows Die Twice
- Elden Ring
- Black Myth: Wukong
- Lies of P

## Features

- Track total deaths across supported games
- Hosted Death Counter Overlay
- Overlay customization and preview
- TXT export
- Global hotkeys

## Getting started

1. Install and open SoulsTracker.
2. Select your game and choose a save or character if prompted.
3. Start playing.
4. If you're streaming, enable hosted Overlay in the Overlay tab, then copy your URL there. New installations start with hosted publication off.

See the [getting-started guide](docs/RELEASE-GETTING-STARTED.md) for additional setup.

Minimize or close the window to keep tracking from the Windows notification area.
Click the SoulsTracker icon or choose **Open SoulsTracker** from its menu to restore
the window. Choose **Exit** in that menu or at the bottom of the window to stop
tracking and quit. You can reach notification-area icons with Win+B, then use
the arrow keys and Enter or Space to open the icon and its menu.
